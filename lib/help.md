# metascope — keyboard

| Key         | Action                            |
| ----------- | --------------------------------- |
| ↑           | line up                           |
| ↓           | line down                         |
| ← / PgUp    | page up                           |
| → / PgDn    | page down                         |
| Home        | top                               |
| End         | bottom                            |
| Space       | toggle status                     |
| /           | search                            |
| n / N       | next / prev match                 |
| l           | toggle line numbers               |
| r           | reload file / directory           |
| ⧉ click     | copy inner code                   |
| fence click | copy example source               |
| ▶ click     | run code block (js/ts/bash)       |
| ■ click     | stop running block                |
| ✕ click     | hide output panel                 |
| drag        | select source (copied on release) |
| click       | clear selection                   |
| y           | copy selection again              |
| Esc         | stop run / clear selection / quit |
| js init     | shared prelude for JS runs        |
| ?           | this help                         |
| Esc / q     | back / quit                       |
